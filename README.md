# 🍽️ Noko Simple Fast Food Website

This repository contains the official website for **Noko Simple Fast Food** — a modern fast-food ordering and menu showcase website built with **HTML**, **TailwindCSS**, and **Vanilla JavaScript**.

The website includes:
- A beautiful hero section  
- Menu with filters  
- Cart system  
- WhatsApp ordering  
- Contact & location  
- Testimonials  
- Dark mode  
- Mobile-friendly UI  
- Floating WhatsApp & call buttons  
- Admin panel (local only)

## 📁 Project Structure


- **index.html** — Main webpage  
- **styles.css** — Custom styles  
- **app.js** — JavaScript for menu filter, cart, admin panel, WhatsApp ordering  
- **assets/** — All images, icons, and media files  

---

## 🚀 Deployment
This website is hosted for free using **GitHub Pages**.

### Steps:
1. Upload all project files to the main branch  
2. Go to **Settings → Pages**  
3. Set:
   - Source: `Deploy from branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. Save  
5. Your site will publish automatically
